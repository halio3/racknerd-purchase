## 先搞清楚买什么：RackNerd 的产品线

RackNerd 的产品分三大类：VPS、独立服务器和共享主机。第一次进官网容易被一堆系列绕晕，其实 VPS 主要是三条线：

- **KVM VPS**：基础款，KVM 虚拟，SSD 磁盘，价格主力都在这里
- **AMD Ryzen Linux KVM VPS**：Ryzen CPU 核心，走高性能路线，适合对 CPU 有要求的人
- **Windows VPS with NVMe SSD**：Windows 系统，需要跑 Windows 软件才选它

拿不准的话按用途倒推：挂脚本、练 Linux，选最便宜的 KVM 款；要跑 Windows 程序，看 Windows 系列；只想建网站、完全不想碰命令行，直接看共享主机。

## RackNerd 购买流程详解

下面以 VPS 为例走一遍完整流程，共享主机大同小异。官网虽然只有英文，但结账要填的字段就那么几项，对照下面的说明填即可。

### 第一步：进套餐配置页

从购买链接进入目标机型，点 Order Now 后到配置页。这里要确认三件事：

1. 付款周期：月付、季付、年付等，周期越长越划算，RackNerd 的价格优势基本都在年付上
2. 机房位置（Location）：可选机房多达 17 家，国内访问建议优先圣何塞和洛杉矶 DC02，响应速度和线路优化相对不错
3. 操作系统和附加项：选要装的系统，需要额外 IP 也在这里加

选完点蓝色 Continue 进入下一步。

### 第二步：优惠码（如果有的话）

Continue 之后进结算页，有优惠码就在输入框填入，点 Validate Code 验证，通过后金额会自动变成折后价。两个提醒：双十一、黑五这类特价机通常本身就是活动底价，不叠加优惠码；常规款可以找第三方优惠码，比如独立服务器有立减 15% 的 15OFFDEDI，能不能用在你的订单上，以结算页的验证结果为准。

### 第三步：填注册信息

可以先注册再买——官网首页右上角点 MY ACCOUNT，进登录页后点 Register；也可以跳过注册，在结算页直接填信息，系统会一并建号。填写时记住两条：国家、州/地区、省份这些字段务必真实，其他信息可以适度简化，但地区信息别乱编；邮箱一定要用能正常收信的，开通信息全发到这里。

### 第四步：选支付方式，提交订单

同一页面往下是支付方式，可选支付宝、PayPal、信用卡、银联卡、比特币等加密货币，以及电汇。国内用户直接选支付宝，不用为 PayPal 单独折腾。选好点 Complete Order 生成账单，再点页面右上角的 Pay now 跳转支付页，完成付款。

### 第五步：收邮件，拿服务器信息

付款完成后你会收到 RackNerd 的邮件，这台 VPS 的 IP、root 密码、SolusVM 控制面板的登录信息都在里面。拿 IP 加 root 密码就能 SSH 登录，开始部署。

还有一个很多教程没提的点：RackNerd 的 VPS 支持免费申请流量翻倍，而且是永久生效，买完可以顺手申请一下，网上有现成的申请教程可查。

## 新手容易踩的坑

- 别照搬旧教程的价格。活动价每年浮动，看到 $9.98 这类数字先确认是哪一年的活动
- 优惠码无效先看机型。特价机基本不参与叠加优惠码，常规款才有得填
- 地区信息别乱填。国家、州省这些字段跟着账单走，写真实的省事
- 邮箱填能收信的。root 密码和面板信息都靠邮件送达，填错了后续很麻烦
